# Visual contract

Research observatory for engineering interviewers. Native HTML/CSS/ES modules;
no framework is needed for a static narrative and bounded precomputed controls.
DESIGN_VARIANCE 6; MOTION_INTENSITY 3; VISUAL_DENSITY 4.
Cool charcoal/off-white semantic themes, muted green accent, sharp edges.
System sans typography and monospace numerical labels. Scientific color maps
have separate, explicitly labeled meanings. Real Sentinel imagery anchors the
asymmetric introduction. Plots retain axes, units, captions and source links.
No decorative telemetry, moving counters, invented measurements or affiliation.
Theme applies to the entire page. Honor reduced motion and system color scheme.
Navigation fits one desktop row; mobile wraps as a deliberate two-row layout.
At 390px all two-column layouts collapse; no document overflow. Controls are
native, labeled, keyboard accessible, with visible focus. Scientific details use
disclosures. Image dimensions are reserved. Loading and failure messages remain
visible if artifacts cannot load. Site paths are relative; deep links use hashes.
Validate both 1440px and 390px rendered layouts, light/dark, main interactions,
network and console, and automated accessibility/performance checks.
