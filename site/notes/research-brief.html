Research question and scope (design choices)

How do controlled platform-velocity mismatch and uncompensated linear Doppler phase affect point-target impulse response and localization, and which automated diagnostics distinguish defocus from displacement?

Hypothesis: quadratic phase mismatch broadens the impulse response; linear phase can shift a sharp peak and evade width-only acceptance. This connects focusing to product reliability without claiming a spaceborne processor or a new algorithm.

Implement a straight, constant-altitude, broadside, stop-and-go stripmap model with a rectangular finite aperture, a small scene and constant scatterer amplitudes. Use a single backprojection algorithm with a direct raw-echo matched inner product as its independent reference. Ignore Earth curvature, atmospheric propagation, antenna gain variation, actual instrument calibration and motion during a pulse. No InSAR, deep learning, proprietary StriX data or satellite telemetry.

Data and deployment constraints

Real study: bounded Poyang Lake VV/VH RTC crops; select same platform/relative orbit and retain identifiers. Source products have already been calibrated and terrain corrected. Locally crop/regrid, mask invalid intensities and compare fixed VV threshold with histogram Otsu. No independent contemporaneous labels have yet been verified; report candidate-water extent and method sensitivity, not flood accuracy. Spatial blocks, not pixels, define resampling units. Sen1Floods11 was considered but rejected because its upstream licence file could not be verified. Do not redistribute its labels.

Anonymous RTC signing/access will be tested before committing to the case. Read bounded COG windows rather than multi-GB scenes; retain unsigned source URLs, never ephemeral tokens. Bundle small licensed crops for credential-free reproduction. Static Pages serves compact generated artifacts; scientific work runs offline/CI. Browser controls select independently generated experiment variants; geometry formulas alone calculate live. Native static assets and hash links avoid server routing and repository-subpath errors.

Validation strategy

Check analytic rectangular-aperture sinc expectations, chirp width ~0.886 c/(2B), azimuth width ~0.886 lambda R/(2L), FFT versus direct convolution and direct raw-echo reference; perturbations, complex inputs, corrupted data and cache hashes. Widths use half-power crossings; sidelobes use first-minimum boundaries and a fixed measurement window. Repeat seeded noise trials and publish effect sizes and empirical uncertainty. Bound processing memory and grids. Regenerate all tables/figures; retain config, dependency lock hash, source hashes and machine details. Verify real CRS, overlap, masks, units and acquisition geometry. Inspect deployed site at desktop/mobile and test controls, citations and paths.

Additional checked primary/library references: - Ulander, Hellsten and Stenstrom, 2003: related fast factorized backprojection paper, DOI 10.1109/TAES.2003.1238734; bibliographic context, not the implemented optimization. - Otsu, 1979: threshold selection by between-class variance, DOI 10.1109/TSMC.1979.4310076; bibliographic record checked, local histogram equation implemented independently. - Playwright assertions, Python Markdown, MDN ES modules: static-note generation and browser checks.
